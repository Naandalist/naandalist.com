I built Tayang as an editorial movie and TV catalog powered by TMDB. The dark, restrained interface gives titles and their stories room to stand out. It is a place to discover what to watch, not a streaming service or a Netflix clone.

## Discover and Save

- Browse catalog rows for movies, TV shows, and popular people.
- Explore dedicated detail pages for movies, TV shows, and people.
- Search across titles and people from one search page.
- Keep a personal watchlist saved in the browser with localStorage.

Loading, empty, and error states keep the experience clear when data is loading or unavailable.

## Built With

Tayang uses React and TypeScript with Vite, Tailwind CSS for styling, React Router for navigation, and TanStack Query for fetching and caching data from TMDB.
