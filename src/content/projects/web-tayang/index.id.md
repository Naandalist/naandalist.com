Saya membangun Tayang sebagai katalog editorial film dan serial TV dengan data dari TMDB. Antarmuka yang gelap dan tenang memberi ruang bagi setiap judul dan ceritanya. Tayang menjadi tempat untuk menemukan tontonan, bukan layanan streaming atau tiruan Netflix.

## Temukan dan Simpan Tontonan

- Jelajahi deretan katalog film, serial TV, dan tokoh populer.
- Buka halaman detail khusus untuk film, serial TV, dan tokoh.
- Cari judul dan tokoh melalui satu halaman pencarian.
- Susun watchlist pribadi yang tersimpan di browser melalui localStorage.

Tampilan loading, kosong, dan error membantu pengguna memahami kondisi aplikasi saat data sedang dimuat atau tidak tersedia.

## Teknologi

Tayang menggunakan React dan TypeScript dengan Vite, Tailwind CSS untuk styling, React Router untuk navigasi, serta TanStack Query untuk mengambil dan menyimpan cache data dari TMDB.
